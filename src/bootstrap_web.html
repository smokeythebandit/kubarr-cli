Load balancer required

Bare-metal clusters need a configured load balancer implementation (for example MetalLB or Cilium). This wizard does not install a controller; the external IP may remain pending until one is available.

Test LoadBalancer creates a TEMPORARY, selectorless LoadBalancer Service to request an address. Cloud providers may charge for these billable resources. If the openresty namespace is absent, the test prepares it and retains it for the future gateway install. The test does not install a load balancer controller.

Cleanup confirms the temporary Service is absent from the Kubernetes API after deletion (including finalizers), but external provider deprovisioning may lag. Passing verifies address allocation capability for only five minutes; it does not reserve an address or prove actual public reachability or guarantee a future deployment.
